# Material interno del equipo

Esta carpeta no forma parte del ZIP para el docente.

- guias/GUIA_EQUIPO.md: instrucciones detalladas, Windows/Linux y pruebas.
- guias/CONTRATOS.md: contratos de las APIs.
- guias/GUIA_EXPOSICION.md: repaso para presentar.
- documentos/GoDeporte_guia_del_equipo.pdf: guía PDF del equipo.
- documentos/: propuesta y presentación de referencia.
- plantilla-servicio/: plantilla de desarrollo.
- tests/: pruebas automáticas.
- scripts/: ayudas de desarrollo.
- task.md: estado del trabajo.

Las rutas indicadas en guías anteriores son relativas a la raíz del proyecto; los documentos se trasladaron aquí sin modificar su contenido. Las pruebas siguen ejecutándose desde la raíz.
